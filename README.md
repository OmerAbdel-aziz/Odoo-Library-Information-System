# Odoo Library Information System

Custom Odoo 19 Community modules for a complete Library Management & Offline Mapping System.

## Modules

| Module | Description |
|---|---|
| `library_base` | Organization structure: branches, floors, sections, shelves |
| `library_catalog` | Books, authors, publishers, classifications, physical copies |
| `library_membership` | Members, membership plans, member types |
| `library_circulation` | Loans, issues, returns, renewals, fines |
| `library_reservation` | Reservations, waiting lists, hold shelf |
| `library_inventory` | Stock integration, branch transfers |
| `library_acquisition` | Purchase requests, procurement |
| `library_serials` | Periodicals, subscriptions |
| `library_digital` | E-books, digital resources |
| `library_events` | Library events, registrations |
| `library_offline_map` | MapLibre-based offline geographic maps |
| `library_mobile` | Bookmobile units, routes, stops |
| `library_portal` | Member self-service portal |
| `library_notifications` | Automated notifications and reminders |
| `library_audit` | Audit trail for sensitive operations |
| `library_dashboard` | KPI dashboards |
| `library_reports` | Reporting and analytics |
| `library_integration` | External system integrations |

## Requirements

- Odoo 19 Community
- PostgreSQL 16+
- Python 3.12+
